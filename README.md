# Saree Delivery Platform

منصة توصيل طعام وطلبات قابلة للتوسع داخل الجمهورية اليمنية.

## المكونات
- Flutter Android: العميل، المطعم، المندوب.
- Node.js + TypeScript API.
- PostgreSQL + migrations.
- لوحة إدارة وموقع ويب.
- GitHub Actions للاختبارات وبناء APK.

## الحالة
المشروع قيد التنفيذ. لا توجد مفاتيح سرية داخل المستودع.
