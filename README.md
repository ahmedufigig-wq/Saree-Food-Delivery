# سريع | Saree Food Delivery

منصة توصيل طعام تبدأ في رداع، اليمن، مبنية باستخدام Flutter وSupabase.

## مكونات المستودع
- تطبيق Android موحد بواجهات بحسب دور الحساب: العميل، المطعم، المندوب، والمدير.
- Supabase Auth لتسجيل الحسابات.
- PostgreSQL مع Row Level Security.
- إجراءات خادمية لإنشاء الطلب والتحقق من الأسعار وتغيير حالة الطلب حسب الصلاحيات.
- تحديثات فورية لحالة طلب العميل عبر Realtime.
- GitHub Actions لبناء APK عند تحديث الفرع main.

## قبل التشغيل
1. أنشئ مشروع Supabase.
2. نفّذ ملفات SQL بالترتيب من `supabase/migrations`.
3. أضف أسرار المستودع `SUPABASE_URL` و`SUPABASE_ANON_KEY` من GitHub → Settings → Secrets and variables → Actions.
4. اتبع [دليل إعداد Supabase](docs/SUPABASE_SETUP.md).

## بناء APK
يعمل سير العمل تلقائيًا عند push إلى `main)، أو يدويًا من GitHub Actions. لن ينشئ APK إذا لم تكن أسرار Supabase موجودة؛ وذلك لمنع تسليم تطبيق غير مربوط بالخادم.

## الحالة
التكامل الأساسي للعميل والمطعم والمندوب موجود في مرحلة التطوير. لا تعتبر المنصة جاهزة للإطلاق التجاري حتى تُنشأ قاعدة Supabase الفعلية، وتُضاف بيانات المطاعم والحسابات، وتنجح اختبارات الأمان والتشغيل الميداني. راجع [خارطة الطريق](docs/PLATFORM_ROADMAP.md).
