# Delivery Roadmap

1. Foundation and database schema.
2. Authentication and RBAC.
3. Restaurant catalog and menus.
4. Cart and ordering.
5. Restaurant operations.
6. Driver dispatch and location workflows.
7. Admin dashboard and reporting.
8. Official website and SEO.
9. CI, tests, APK build, release verification.

A stage is not marked complete merely because UI exists; its functional flow and tests must be implemented.
